# Drogas UCI — proyecto Android

Tu HTML está en app/src/main/assets/index.html y se muestra en un WebView a pantalla completa (funciona sin internet; localStorage habilitado).

## Opción A: compilar gratis con GitHub (sin instalar nada)
1. Creá un repositorio nuevo en github.com.
2. "Add file > Upload files" y arrastrá TODO el contenido de esta carpeta (incluida la carpeta oculta .github). Conviene hacerlo desde una PC.
3. Pestaña "Actions" > esperá que termine "Compilar APK" (~3 min).
4. Abrí la ejecución > sección "Artifacts" > descargá DrogasUCI-apk (zip con el .apk).
5. Pasalo al celular, abrilo y permití "instalar apps de origen desconocido".

## Opción B: Android Studio
Abrir esta carpeta con Android Studio > Build > Build APK(s).

Para actualizar la app: reemplazá index.html y volvé a compilar.
